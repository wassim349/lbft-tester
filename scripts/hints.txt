# Conseils affiches sous les erreurs du bilan (💡).
#
# Format : <fonctions><TAB><regex><TAB><conseil FR><TAB><conseil EN>   (une ou plusieurs tabulations)
#   fonctions : regex sur le nom (ex. ft_atoi, ft_is(alpha|print)), ou * pour toutes
#   regex     : regex etendue (awk), testee sur chaque erreur de la fonction, mise sur une ligne,
#               TOUJOURS EN FRANCAIS (trace.key), quelle que soit la langue affichee :
#                 "TEST ft_atoi("-42") → retour attendu -42, obtenu 0"     (test raté)
#                 "COMPIL ne compile pas : ft_x.c:12:3: error: ..."         (fichier écarté)
#                 "PROTO type" / "PROTO const"                            (prototype du .c)
#                 "NORM SPACE_BEFORE_FUNC message"                        (norminette)
#               ecrire \\x80 pour un \x80 litteral, \( pour une parenthese
#   conseil   : une phrase qui dit OU chercher (le cas qui coince, le man ou le sujet a relire),
#               JAMAIS la reponse : pas de code, pas de correction. Pas de tabulation dedans.
#   Une regle propre a une fonction (pas *) ne s'applique qu'aux lignes TEST (et PROTO si sa regex
#   commence par ^PROTO). Les conseils de norme ne sont affiches qu'une fois dans tout le bilan.
#
# La premiere regle qui correspond gagne : les regles precises d'abord, les generales a la fin.
# Apres une modification : make i18n (verifie la colonne anglaise et les regex) puis make selftest.
